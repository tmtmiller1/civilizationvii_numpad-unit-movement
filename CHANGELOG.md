# Changelog

All notable changes to Numpad Unit Movement are documented here. This project follows semantic versioning.

## [0.1.0] - 2026-10-13

- First version. The number pad moves the selected unit one tile in eight directions, as a right-click on that tile
  would. 8 and 2 travel straight up and down the map.
- Each direction's key can be changed in Options > Add-ons.
